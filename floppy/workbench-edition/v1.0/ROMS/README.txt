========================================
 RetroDrive Workbench Edition
 System ROM
========================================

The system ROM required by the emulator is
NOT included with RetroDrive.

To use RetroDrive Workbench Edition, you must
provide a compatible system ROM.

Please obtain the ROM legally from an authorized
source or from your own original hardware/software.

Once you have obtained the required ROM, copy it
into this folder:

EMULATOR/ROM/

The emulator will look for the system ROM in this
location.

IMPORTANT:
RetroDrive does not provide, distribute or host
copyrighted system ROM files.

If you do not have the required ROM, search online
for the official or legally licensed source from
which it can be obtained.
